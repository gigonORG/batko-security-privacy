BATKO SECURITY

Privacy Policy · Test Edition

Last updated: November 12, 2026

BATKO SECURITY is a Chrome extension that displays a local password-controlled lock screen for chatgpt.com. It is intended to discourage casual access to ChatGPT in the browser. It does not protect an OpenAI account or replace account authentication.

Data processed locally

When a user creates a password, the extension derives a verification hash using PBKDF2 with SHA-256, a randomly generated salt and 180,000 iterations. It stores the salt and hash, along with extension preferences and lock-related status (including unsuccessful-attempt counts), using chrome.storage.local on the user's device. The extension does not store the password itself as plain text.

Website access

The extension operates on https://chatgpt.com/* to display its lock screen. It uses browser tab permissions to target the active ChatGPT tab when a user requests a lock. It does not intentionally collect the content of ChatGPT conversations.

Transmission and sharing

The reviewed version 0.3.0 contains no functionality to transmit the stored password verification data, conversations, browsing history, or other personal information to the developer or third-party servers. It does not sell user information or use it for advertising or creditworthiness assessments.

Retention and control

Locally stored extension settings remain on the device until cleared by the user or the browser, such as when extension data is removed. Users can remove the extension using Chrome's extension management controls.

Security limitations

The extension is a convenience privacy layer. Users may disable or uninstall it through their browser, and it does not restrict access to ChatGPT from other browsers, devices, or sessions.

Changes

If the extension's data practices change in a future release, this policy will be updated accordingly.

Contact

For questions about this privacy policy, please use the developer contact details provided on the BATKO SECURITY Chrome Web Store listing.
